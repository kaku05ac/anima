# Anima

Jak rozumieć duszę – 2800 lat sporu w 3 ścieżkach: Filozofia, Pismo, Kościół.

Interaktywna oś czasu: każda linia wychodzi z jednego punktu nad duszą i kończy się kropką – jedną osobą albo jednym dokumentem z jedną tezą. Suwak na dole wybiera okres; linie reagują na kursor.

## Uruchomienie

Wystarczy otworzyć `index.html` w przeglądarce albo włączyć GitHub Pages (Settings → Pages → branch `main`, folder `/`).

## Pliki

- `index.html` – cała strona (HTML, CSS, JS w jednym pliku)
- `video/background.mp4` – tło (pętla)
- `images/background-poster.webp` – klatka startowa tła
